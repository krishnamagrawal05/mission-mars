# MISSION: MARS — Ultimate Edition

## Run it
1. Extract this ZIP.
2. Open the `Mission-Mars-Ultimate` folder in VS Code.
3. Open `index.html` with Live Server (recommended), or double-click it.
4. Everything works with plain HTML/CSS/JavaScript. No npm or Three.js setup is required.

## Included
- Cinematic loading screen
- Animated starfield
- Mars hero scene
- Earth → Mars journey timeline
- 10-second rocket launch
- Mission Control live telemetry
- Interactive rover hotspots
- Mars landscape cards
- Martian weather simulator
- Search-for-life laboratory
- Earth ↔ Mars communication delay
- Astronaut crew section
- Modular Mars base builder
- Martian Sol clock
- Future timeline
- Mission score
- Mobile hamburger menu
- Sound interaction
- Easter egg: press M
- Responsive mobile layout

## Important
This version uses CSS-generated cinematic visuals instead of external MP4/3D assets, so it is fast and reliable for a deadline. Internet is only needed for the optional Google Fonts import.
